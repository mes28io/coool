# Provider marks

The marks coool shows next to sessions to say which service runs them.

| File | What | Source |
|---|---|---|
| `claude.svg` | The Claude mark, in its own orange (`#D97757`) | Anthropic's Claude Code editor extension, `resources/claude-logo.svg` (v2.1.84), copied unchanged |
| `openai.svg` | The OpenAI mark (used for Codex) | OpenAI's ChatGPT/Codex desktop app bundle (`app.asar`, `webview/assets/520ae36faaea.svg`, group "OpenAI Logo"). The path is unchanged; its fill is `currentColor` so it follows the text colour (the mark is monochrome), and a full-canvas clip rect that clipped nothing was dropped |

Both are rendered as is: no reshaping, no recolouring beyond the above.
